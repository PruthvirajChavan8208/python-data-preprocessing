# Data Preprocessing & Data Cleaning Portfolio

Welcome to my Data Preprocessing repository! This project serves as a practical portfolio demonstrating my end-to-end data cleaning and data auditing workflows using Python, Pandas, and NumPy. 

The sole focus of this repository is Data Sanitization—transforming raw, messy, or corrupted tracking files into pristine, zero-fault, analysis-ready datasets by systematically eliminating missing values, removing structural outliers, and verifying deduplication.
